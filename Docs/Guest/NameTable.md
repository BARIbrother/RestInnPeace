# 손님 이름 테이블

한 회차에서 손님마다 서로 다른 이름을 하나씩 뽑는다. 풀이 손님 수보다 적으면 남는 인원은 `손님 #Id`로 떨어진다.

코드 쪽 목록은 `GameData.GuestNames`다. 여기와 맞춰 둔다.
