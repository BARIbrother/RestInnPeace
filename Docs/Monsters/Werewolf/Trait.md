# 늑대인간 특성 (프로토타입 확정)

## 이층 구조

| 층 | 언제 정해지나 | 플레이어에게 | 역할 |
| --- | --- | --- | --- |
| 종족 공통 특성 | 종족 고정 | 회차 시작 시 종족과 함께 공개 | 정체성. 항상 성립 |
| 회차 랜덤 특성 (표적 슬롯) | 회차 시작 시 1개 선정 | 숨김. 헌터 손님·관찰로 유추 | 이번 판의 타깃 위치 규칙 |
| 회차 랜덤 특성 (예고 슬롯) | 회차 시작 시 1개 선정 | 숨김. 헌터 손님·관찰로 유추 | 이번 판의 2단계 변형 |

손님 **직업**과 이름이 겹치지 않는다. 직업은 손님의 인지·요청, 몬스터 특성은 사냥 규칙의 변형.

## 종족 공통 (공개)

| 이름 | 내용 |
| --- | --- |
| 삼단 사냥 | 1단계(탐색) → 2단계(예고) → 3단계(공격). 단계 사이 휴식 0일. |
| 인간 위장 | 손님 직업 1개를 가진다. 진영은 직업으로 판정되지 않는다. |

## 회차 랜덤: 표적 슬롯 (프로토타입)

회차당 1개. 균등 확률. 범위에 인간이 없으면 폭주 (`03_MonsterPattern.md`).

| 특성 | 타깃 범위 | 헌터 힌트 예 |
| --- | --- | --- |
| 같은 층 집착 | 같은 층 무작위 인간 | 같은 층의 인간을 노린다 |
| 인접 추적 | 상하좌우 1칸 방의 무작위 인간 | 이웃한 방의 인간을 노린다 |
| 배회 사냥 | 여관 전체 무작위 인간 | 여관의 인간을 가리지 않고 노린다 |

## 회차 랜덤: 예고 슬롯 (프로토타입)

회차당 1개. 균등 확률.

| 특성 | 2단계 효과 | 헌터 힌트 예 |
| --- | --- | --- |
| 영역 표시 | 타깃 방에 `[털]` | 털을 남기는 짐승이다 |
| 문 앞의 사냥꾼 | 타깃 방 `[문 앞을 서성임]` | 문 앞에서 서성인다 |
| 침묵의 접근 | 2단계 단서 없음. 공격이 잠금·향에 막히면 `[문을 긁은 자국]` | 다가와도 흔적을 거의 남기지 않는다 |

## 프로토타입 고정값

| 항목 | 값 |
| --- | --- |
| 표적 | 표적 슬롯 1개 랜덤 (위) |
| 처치 | `[비명을 지름]` 후 사망 |
| 휴식 | 1→2: 0일, 2→3: 0일 |
| 대응 | 약제사 향·문 잠금이 통함 |

## 이후 확장 (미구현)

처치·내성 슬롯. 표적 필터/우선순위 후보는 아래 참고용.

### 표적 필터·우선 후보

| 특성 | 효과 |
| --- | --- |
| 약한 냄새 | 약제사 향 없는 방 우선 |
| 잠긴 문 기피 | 잠긴 방 제외 |
| 목격자 처단 | 전날 관련 증언자 우선 |

### 처치 후보

| 특성 | 효과 |
| --- | --- |
| 물어뜯기 | 비명 후 사망 (현재 기본) |
| 숨죽인 이빨 | 비명 없이 사망 |
| 문 부수기 | 잠금 무시 |
| 한 방의 짐승 | 잠금에 막히면 타깃 포기 |

### 내성 후보

| 특성 | 효과 |
| --- | --- |
| 향 기피 | 약제사 향이 패턴 차단 (현재 기본) |
| 향에 끌림 | 약제사 향 방을 우선 타깃 |
| 철저한 경계 | 잠근 사람을 다음 타깃 후보에 넣음 |
