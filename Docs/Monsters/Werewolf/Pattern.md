# 늑대인간 패턴 (프로토타입)

3단계 고정. 단계 사이 휴식 0일. 상세 변형은 `Trait.md` 표적·예고 슬롯.

## 타깃 선정 (표적 슬롯)

| 특성 | 범위 | 비고 |
| --- | --- | --- |
| 같은 층 집착 | 같은 층 무작위 인간 | 범위에 인간이 없으면 폭주 |
| 인접 추적 | 상하좌우 1칸 무작위 인간 | 범위에 인간이 없으면 폭주 |
| 배회 사냥 | 여관 전체 무작위 인간 | 사실상 폭주와 범위가 같음. 향·잠금만으로 비움 |

## 1단계

| 내용 |
| --- |
| 타깃 선정 후 타깃 방 앞에서 `[복도를 돌아다님]`. 즉시 2단계로. |

## 2단계 (예고 슬롯에 따라 다름)

| 예고 특성 | 내용 |
| --- | --- |
| 영역 표시 | 타깃 방에 `[털]`. 즉시 3단계로. |
| 문 앞의 사냥꾼 | 타깃 방 `[문 앞을 서성임]`. 즉시 3단계로. |
| 침묵의 접근 | 단서 없음. 즉시 3단계로. |

잠긴 타깃 방이면 2단계를 수행하지 못한다.

## 3단계

| 내용 |
| --- |
| 타깃 공격. 성공 시 타깃은 `[비명을 지름]` 후 사망. |
| 문이 잠겼거나 약제사 향이 있으면 실패. `[문을 긁은 자국]` (특히 침묵의 접근에서 유일한 흔적). |

## 다음 날 밤의 분기

| 조건 | 결과 |
| --- | --- |
| 타깃이 죽었을 때 | 1단계로 |
| 타깃이 죽지 않았고, 여전히 공격 범위 안에 있을 때 | 0일 휴식 후 3단계 |
| 타깃이 죽지 않았고, 공격 범위 밖으로 벗어났을 때 | 1일 휴식 후 1단계 |
