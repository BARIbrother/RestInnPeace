## 공격 패턴 목록

공격이 어떤 과정으로 진행되는지

### 1단계


|                                                         | 가중치 |
| ------------------------------------------------------- | --- |
| 타깃으로 선정된 인간 방 앞에서 [복도를 돌아다님] 성공 시 1일 휴식 후 2단계로 전환 |     |
| 타깃으로 선정된 인간 방 앞에서 [복도를 돌아다님] 성공 시 2일 휴식 후 2단계로 전환 |     |


### 2단계


|                                      | 가중치 |
| ------------------------------------ | --- |
| 타깃 방에 [털] 발생. 성공 시 1일 간 휴식 후 3단계로 전환 |     |
| 타깃 방 [문 앞을 서성임]. 성공 시 1일 간 휴식 후 3단계로 전환 |     |


### 3단계


|                                   | 가중치 |
| --------------------------------- | --- |
| 타깃 공격. 공격 성공 시 타깃은 [비명을 지름] 후 사망. |     |
