# 02. 몬스터

- 밤 행동 속도: 큰 단위로 설정한다. 모드로 종족을 추가할 때 기존 값 사이에 정수로 끼워 넣을 수 있게 하여, 같은 속도로 인한 순서 충돌이나 소수점 속도를 피한다.
  - 값이 클수록 먼저 행동한다.


| 종족 이름 | 고유 특성                                                                                   | 밤 행동 속도 |
| ----- | --------------------------------------------------------------------------------------- | ------- |
| 흡혈귀   | 낮에 방에서 절대 안 나옴. 행동 유도에도 응하지 않음                                                          | 70      |
| 늑대인간  | 없음                                                                                      | 100     |
| 좀비    | 방에서 냄새가 남. 옆방 인간은 사망 시 좀비로 변함                                                           | 0       |
| 아귀    | 인간 공격해 죽일 시 시체를 먹어, 겉보기엔 손님이 방 안에 있는 것과 똑같이 표기됨. 플레이어가 로비로 부르기를 시도해 시체를 발견하기 전까지 사망 공개 안 함 | 50      |
| 도꺠비   | 상하좌우 방을 시끄럽게 함                                                                          | 30      |
