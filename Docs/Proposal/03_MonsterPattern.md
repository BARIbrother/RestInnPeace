# 03. 몬스터 패턴

- 괴물의 밤 행동은 타깃 / 공격 과정 / 효과적인 대응 / 기타 변수 4개 조각으로 나뉜다.
  - 회차 시작 시 괴물 종류별로 각 표에서 조각을 1개씩 가중치에 따라 무작위로 선정한다. 여러 몬스터가 같은 조각을 가질 수도 있다.
  - 기타 변수는 없을 수도 있다.
  - 조각은 서로 어긋나는 조합이 나오지 않도록 작성한다. 조합 제한 규칙은 추후 설정한다.
  - 정보원은 선정된 조각을 무작위 순서로 1개씩 알려 준다.
  - 폭주: 타깃을 선정할 때 타깃 범위에 인간이 없으면, 여관의 생존 인간 전체(주인 제외) 중 무작위 1명을 타깃으로 삼는다.
    - 폭주로 타깃을 정한 밤에 한 번 밤사이 로그에 "괴물의 분노가 느껴집니다..."를 남긴다. (`06_NightLog.md`)
    - 이후 단계는 평소와 같이 진행하며, 설비도 평소와 같이 통한다. 폭주 타깃은 범위와 상관없이 공격 범위 안에 있는 것으로 본다.
    - 폭주는 다음 타깃 선정 때 풀리며, 그때 범위를 다시 확인한다.
  - 진행 중 타깃이 다른 이유로 사망하면 다음 날 새 타깃 선정
  - 마지막 단계 이후의 진행은 종족별 `Pattern.md`의 "다음 날 밤의 분기"를 따른다.
  - 가중치가 비어 있으면 같은 표의 후보끼리 균등 확률
