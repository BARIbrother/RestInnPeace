# 03. 몬스터 패턴

- 괴물의 밤 행동은 **종족 공통 특성** + **회차 랜덤 특성(슬롯)** 으로 정한다.
  - 종족 공통: 해당 종족이면 항상 성립. 회차 시작 시 공개해도 된다.
  - 회차 랜덤: 슬롯별로 후보 중 가중치/균등으로 선정. 프로토타입 늑대인간은 **표적·예고 슬롯 각 1개** 랜덤.
  - 상세는 종족별 `Docs/Monsters/<종족>/Trait.md`, `Pattern.md`, `Counter.md`를 따른다.
  - 선정된 회차 특성 힌트는 헌터 계열 손님이 알려 준다. (`05_1_GuestJob.md`) 외부 정보원은 없다.
  - 폭주: 타깃을 선정할 때 타깃 범위에 인간이 없으면, 여관의 생존 인간 전체(주인 제외) 중 무작위 1명을 타깃으로 삼는다.
    - 폭주로 타깃을 정한 밤에 한 번 밤사이 로그에 "괴물의 분노가 느껴집니다..."를 남긴다. (`06_NightLog.md`)
    - 이후 단계는 평소와 같이 진행하며, 대응 수단도 평소와 같이 통한다. 폭주 타깃은 범위와 상관없이 공격 범위 안에 있는 것으로 본다.
    - 폭주는 다음 타깃 선정 때 풀리며, 그때 범위를 다시 확인한다.
  - 진행 중 타깃이 다른 이유로 사망하면 다음 날 새 타깃 선정
  - 마지막 단계 이후의 진행은 종족별 `Pattern.md`의 "다음 날 밤의 분기"를 따른다.

## 늑대인간 (프로토타입 요약)

- 공통: 삼단 사냥, 인간 위장
- 랜덤 표적 1개: 같은 층 집착 / 인접 추적 / 배회 사냥
- 랜덤 예고 1개: 영역 표시 / 문 앞의 사냥꾼 / 침묵의 접근
- 대응: 약제사 향, 문 잠금 (`Counter.md`)


## (참고) 구 4조각 시스템

타깃 / 공격 과정 / 효과적인 대응 / 기타 변수 조각 방식은 슬롯 특성으로 대체했다.
