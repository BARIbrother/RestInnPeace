# 툴팁 설명

- 게임 내 텍스트에서 태그 이름에 커서를 올리면 해당 행의 툴팁 설명을 띄운다.
- 태그 이름은 게임 내 표기와 똑같이 적는다. (예: `[털]`, `불결함`)
- 표 칸 안에서 줄을 바꾸려면 `<br>`을 쓴다.

## 단서


| 번호  | 태그 이름      | 툴팁 설명                                |
| --- | ---------- | ------------------------------------ |
| 1   | [복도를 돌아다님] | 그 층의 사람들이 움직임을 느낍니다.                 |
| 2   | [비명을 지름]   | 당신과 주변 8칸의 사람들이 비명을 듣습니다.            |
| 3   | [문 앞을 서성임] | 방 앞에서 탐색합니다. 예민한 사람은 이를 알아차릴 수 있습니다. |
|     |            |                                      |

## 설비


| 번호  | 태그 이름     | 툴팁 설명                               |
| --- | --------- | ----------------------------------- |
| 1   | 녹슨 감금 자물쇠 | 설치하면 그 방의 사람은 그날 밤 방에서 나오지 못하게 합니다. |
| 2   | 녹슨 방범 자물쇠 | 설치하면 그날 밤 동안 그 사람의 방에 들어가지 못하게 합니다. |
