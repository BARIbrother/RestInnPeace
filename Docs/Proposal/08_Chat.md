# 08. 대사

현재 프로토타입 기준. 대화는 **회의** 단계에서만 한다.


## 표기 규칙

| 표기 | 의미 |
| --- | --- |
| `{speaker}` | 말하는 손님 표시 이름 |
| `{target}` | 지목·피의심 대상 손님 이름 |
| `{name}` | 그 외 한 명의 이름 (문 앞 서성임 당사자 등) |
| `{name_1}`, `{name_2}` | 이름 둘 이상일 때 |
| `{room}` | 객실 표시 이름 (예: 101호실) |
| `[태그]` | 게임 내 단서·이벤트 태그. 툴팁은 `09_GuideDescription.md` |

- 표 칸에서 줄을 바꾸려면 `<br>`을 쓴다.
- `{…}`는 실행 시 실제 이름으로 치환한다. 중괄호 안 키 이름만 의미가 있다.
- 같은 분류·조건에 여러 줄이 있으면 **무작위 1개**.
- **어젯밤 일** 우선순위: 과묵함 > 괴물에게 공격받아 살아남음 > 숙면가 > 나머지 후보 중 무작위.
- 과묵함 손님은 회의 **주장**에도 참여하지 않는다 (발언 없음).
- **회의 주장**은 반드시 누군가(`{target}`)를 의심·지목한다. 단순 목격·단서 나열은 어젯밤 일로 둔다.


## 단계별 사용처

| 분류 | 언제 |
| --- | --- |
| 회의 주장 | 회의 시작 시, **누군가를 지목하는** 발언만 테이블에 올림. 반박되지 않으면 채택 → 의심 +1 |
| 어젯밤 일 | 회의 중 로비 손님과 1:1 대화 (손님당 하루 1회, 1일차 불가). 정보·분위기용. 의심은 직접 안 올림 |
| 주인 거짓 주장 | 주인이 신뢰를 쓰고 올리는 가짜 **지목** 주장 |


## 회의 주장


| 번호 | 조건 | 대사 | 지목 | 비고 |
| --- | --- | --- | --- | --- |
| C1 | 로비 참가 + 어젯밤 `{target}`의 [복도를 돌아다님]을 앎 | 어젯밤에 말이죠… `{target}`이(가) 복도를 돌아다니는 걸 봤어요. | `{target}` | 목격 → 지목 |


## 주인 주장


| 번호 | 조건 | 대사 | 지목 | 비고 |
| --- | --- | --- | --- | --- |
| H1 | 신뢰 소모로 거짓 주장 | (주인) `{target}`… 아무래도 수상합니다. 증거도 있어요. | `{target}` | 거짓 |
| H2 | 보유 [털] 단서 1장 소비해 제시 | (주인) 이 털을 보십시오. `{target}`의 소행이 분명합니다. | `{target}` | 진짜 단서 제시 |


## 어젯밤 일 (1:1 대화)


| 번호 | 조건 | 대사 | 비고 |
| --- | --- | --- | --- |
| 1 | [복도를 돌아다님]이 난 층의 손님 (본인 제외). 이름 특정 목격 없음 | 어제 복도에서 누가 돌아다니더라고. | |
| 2 | [비명을 지름] 방 주변 8칸 손님 (본인 제외) | 어제 비명 소리가 들렸어. | |
| 3 | [대담함] + 자기 방 [문 앞을 서성임] | 어제 `{name}`이 내 방 앞에 서 있었어. 바로 문 열고 무슨 짓이냐고 따졌지. | `{name}`: 서성인 사람 |
| 4 | 본인이 [복도]/[문 앞]으로 밖에 있었고, 같은 층에 다른 [복도] 손님이 있음 | 어젯밤에 밖을 좀 둘러보는데.. `{name}`을 봤었어. | `{name}`: 다른 배회자 |
| 5 | 본인이 [복도] + 같은 층에 [문 앞을 서성임] | 어젯밤에 밖을 좀 둘러보는데.. `{name_1}`이 `{name_2}` 방 앞에 서 있더라고. 무슨 짓을 했는지는 모르겠다. | |
| 6 | 이벤트 범위 밖 / 숙면가 / 과묵함 | 어젯밤..? 글쎄, 아무 소리도 안 들리던데. | 과묵·숙면은 이 대사만 |
| 7 | 괴물에게 공격받았으나 살아남음 | 죽을 뻔 했다고!! 어떤 놈이 내 방 문을 열고 쳐들어왔어! 다행히 목숨은 건졌지만.. 불안해서 미칠 것 같아.. | 최우선에 가깝게 |
| 8 | [문 앞을 서성임] 실행자 + 그 방 주인이 [비명을 지름] | 어제는 `{name_1}` 방문 앞에 좀 서 있었는데, 갑자기 비명을 지르더라니까.. 깜짝 놀랐어. | `{name_1}`: 대상 방 주인 |
| 9 | 자기 방에 [털]이 남아 있음 + **탈모가 아님** | 제 방바닥에… 털이 떨어져 있었어요. 누가 들어온 거 아닌가요? | 자기가 떨어뜨린 털(탈모)은 말하지 않음 |


## 구현 메모

- 회의 주장 = 지목만. [털] 발견 같은 단서 나열은 어젯밤 일.
- `ChatText`(코드)와 이 표의 문구를 맞춘다.
- 주장과 1:1 대화는 별개다. 주장은 회의 시작 시 자동, 대화는 플레이어가 손님을 골라 듣는다.
