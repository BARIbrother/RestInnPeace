# 08. 대사

- 표 칸 안에서 줄을 바꾸려면 `<br>`을 쓴다.
- 같은 분류의 조건 여러 개에 해당하면 무작위 1개. 단 어젯밤 일은 과묵함 > 괴물에게 공격받았으나 살아남음 > 숙면가 > 나머지 무작위 순으로 우선한다.
