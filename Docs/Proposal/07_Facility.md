# 07. 설비

- 획득·설치·지속 공통 규칙은 `01_Concept.md` 8-4-4 설비를 따른다.
- 가격: 설치할 때 소모하는 [신뢰]. 임시값, 테스트 후 조정 (`10_Trust.md`)


| 이름        | 가격  | 설명                                                                 |
| --------- | --- | ------------------------------------------------------------------ |
| 녹슨 감금 자물쇠 | 1   | 하루 동안 밤에 그 방에서 나가는 것 방지. 감금 자물쇠를 단 방의 괴물은 그날 밤 아무것도 못 함            |
| 녹슨 방범 자물쇠 | 1   | 하루 동안 밤에 그 방을 향한 공격 시도 방지. 다시 달 수 있음. 특성에 따라 무시될 수 있음              |
| 주인 방 자물쇠  | 구입 불가 | 회차 시작 시 2개 기본 지급. 보충 불가. 모든 특성을 무시하고 공격을 막음. 공격을 1회 막으면 파괴되며 회복 없음 |
| 투구꽃 향수    | 2   | 방에 설치하면 그 방 손님을 향한 패턴을 하루 막아 줌                                      |
