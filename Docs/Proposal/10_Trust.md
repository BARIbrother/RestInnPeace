# 10. 신뢰·로비

- 낮 행동과 설비에 쓰던 재화(행동 포인트, 보급 허가증)를 [신뢰] 하나로 합친다.
- 수치는 모두 임시값이며 테스트 후 조정한다.


## 로비

- 낮에 방에서 나온 손님은 로비에 모인다.
- 로비에 모인 손님에게서 이야기를 들을 수 있다. 대화는 신뢰를 쓰지 않으며, 손님 1명당 하루 1회.
- 대화는 로비에 나온 손님하고만 할 수 있다. 방에 틀어박힌 손님과 대화하려면 신뢰를 써서 로비로 불러야 한다.
- 로비 전체에 한 번에 묻는 대화는 없다. 대화는 항상 손님 1명과 한다.


## 신뢰

- 시작 신뢰: 5
- 하한 0. 신뢰가 부족하면 해당 행동을 할 수 없다.
- 이월: 쓰지 않은 신뢰는 계속 남는다.


### 사용처


| 행동         | 소모  | 비고                                    |
| ---------- | --- | ------------------------------------- |
| 방 조사       | 1   | 손님이 로비에 나와 있거나 빈 방일 때                 |
| 로비로 부르기    | 1   | 항상 성공함. 소집·조사 단계에서만 가능                                   |
| 방 교환       | 1   |                                       |
| 설비 설치      | 설비별 | 가격은 `07_Facility.md`를 따른다             |
| 특성 검증      | 2   | 집중 심문에서 사용                            |
| 처형         | 6   | 아래 처형 항목 참고                           |


### 획득처


| 조건                      | 변화  |
| ----------------------- | --- |
| 집중 심문에서 특성을 맞힘          | +3  |
| 집중 심문에서 특성을 틀림          | -2  |
| 설비로 공격을 막음([문을 긁은 자국])  | +2  |
| 밤사이 사망자 없이 아침을 맞음       | +1  |
| 손님 사망                   | -2  |
| 괴물 처형 성공                | 처형에 쓴 신뢰 반환 |


## 집중 심문

- 낮에 정해진 횟수만큼 로비에 나온 손님 1명을 골라 집중 심문한다. 신뢰를 쓰지 않는다.
  - 기본 하루 1회. 난이도가 오르면 손님 수·특성 수와 함께 횟수도 늘어난다.
- 심문에서는 아래 중 하나를 한다.
  - 특성 맞히기: 그 손님이 가진 특성 1개를 지목한다. 맞히면 특성이 확정되고 신뢰 상승, 틀리면 신뢰 하락.
  - 특성 검증: 신뢰를 내고 그 손님의 특성 1개를 확인한다. 검증으로 알아낸 특성은 맞히기 보상 대상이 아니다.
- 이미 확정된 특성은 다시 맞힐 수 없다.
- 검증 수단(아이템 형태 등)은 추후 기획. 재고는 무한이며 신뢰만 소모한다.


## 처형

- 신뢰를 크게 소모해 손님 1명을 처형한다. 처형된 손님은 정체가 공개되고 여관에서 사라진다.
- 괴물을 처형하면 쓴 신뢰를 돌려받는다. 괴물을 모두 처형하면 즉시 승리.
- 인간을 처형하면 쓴 신뢰는 돌려받지 못하고, 그 인간은 사망한다. 손님 사망에 의한 신뢰 하락은 따로 적용하지 않는다.
