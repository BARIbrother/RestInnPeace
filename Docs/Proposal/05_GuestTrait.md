# 05. 손님 특성

- 모든 투숙객(괴물 포함)에게 특성이 있으며, 플레이어에게는 보이지 않는다.
- 괴물과 똑같은 단서를 남기기도 하고, 플레이어에게 이득이나 불이익이 되기도 한다.


| 특성 이름  | 효과                                                       |
| ------ | -------------------------------------------------------- |
| 불결함    | 같은 층의 방에게 [냄새]를 풍김                                       |
| 저녁형 인간 | 낮에 스스로 방에서 나올 확률이 20%로, 더 낮음. 로비로 부르면 응함. 밤에 [복도를 돌아다님]. |
| 겁쟁이    | 같은 층에 [복도를 돌아다님] 또는 자기 방 [문 앞을 서성임]이 있던 밤에 [비명을 지름]      |
| 과묵함    | 밤에 일어난 일을 이야기하지 않음                                       |
| 숙면가    | 밤에 이벤트([복도를 돌아다님], [비명을 지름], [문 앞을 서성임])를 인지하지 못 함       |
| 괴력     | 인간일 경우 50% 확률로 괴물에게 공격받고도 생존 괴물일 경우 방 자물쇠 무시하고 공격 가능     |
| 탈모     | 매일 밤 자기 방에 [털]을 떨어트림                                     |
| 대담함    | 자기 방을 [문 앞을 서성임] 발생 시 문을 열고 당사자의 얼굴을 확인함                 |
| 의심 많음  | 낮 회의에 참가한 사람 중 무작위 한 명을 집어 밤에 [문 앞에 서성임]                 |
| 목이 쉼   | [비명을 지름] 불가.                                             |
