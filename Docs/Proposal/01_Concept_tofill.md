# 01_Concept 빈칸 표

`01_Concept.md`를 채우기 위한 질문 목록이다. `답변` 칸을 채우거나 `01_Concept.md`에 직접 적은 뒤 반영을 요청하면, 채워진 항목은 `01_Concept.md`에 반영하고 이 표에서 삭제한다.
모르는 항목은 비워 두거나 `미정`으로 적는다.

상태 값: `미반영`(답 없음) / `미정`(아직 결정 안 함)
