# 게임 내 문구 목록 (원본 / 개선안)

> 게임 안에 실제로 표시되는 모든 한국어 문구를 모았다. 개선안 칸을 채우면 그대로 코드에 반영한다.
> `{...}`는 런타임에 치환되는 값이다. 개선안에서도 같은 자리표시자를 유지한다.
>
> 출처 표기: `GameData` = `Assets/Scripts/Prototype/GameData.cs`, `View` = `InnGameView.cs`, `Game` = `InnGame.cs`, `Cell` = `View/Rooms/*.cs`
