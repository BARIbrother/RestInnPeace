# 테스트 플레이 개선점

> "반영해 줘" 요청 시
>
> - **즉각 수정**: 에이전트가 바로 코드에 반영하고, 반영된 항목은 `[x]`로 체크한다.
> - **검토 필요**: 코드는 수정하지 않고, 피드백과 아이디어를 `Improvements_feedback.md`에 정리한다.

## 즉각 수정

- [x] 호실 칸 밑에 외출 여부 표기하던 란은 이제 필요 없음
- [x] 검증이란 건 추후 구현할 아이템들을 신뢰도 소모해 사용하는 컨셉으로, 특정한 특성을 갖고 있는지/아닌지만 판정하는 것. 정답을 알려주는 게 아님.
- [ ] 굳이 대화 카테고리를 3개로 나눌 필요 없이 '어젯밤 일' 1개로 통합.

## 검토 필요

- 검증은 추측한 특성을 100% 확정하는 수단이어야 하는데, 신뢰를 소모하면 특성을 찍어서 틀리는 것과 별 차이가 없음 → `Improvements_feedback.md` 참고
